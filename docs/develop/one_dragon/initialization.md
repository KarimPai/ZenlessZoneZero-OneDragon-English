# 初始化流程规范

> 相关文档：[一条龙整体架构](one_dragon_architecture.md) | [应用插件系统](modules/application_plugin_system.md)

需要初始化的内容划分为以下部分

- 普遍应用需要: 应该在启动时异步初始化，初始化完成后才能开始执行应用。
  - OCR
  - ScreenInfo
- 特定应用需要: 在对应 `Application` 的节点里加载，尽量利用游戏画面加载的节点进行初始化。
  - YOLO模型
  - 应用配置
  - 应用运行记录
  - 图片模板
  - 自动战斗配置
  - 游戏数据配置
- UI需要：同上，在切换到特定页面时才进行加载，如果某页面需要加载大量资源，再额外考虑提前异步初始化。
- 其他：不是很必要，做了比没做有用的初始化，在启动时异步初始化，无需关心结果。
  - github proxy 的更新
  - 特定UI需要的提前初始化

## 普遍应用需要

1. 创建 `ZContext`。
2. 异步初始化 `ZContext.init_async`。
3. 运行应用前等待步骤2初始化完成，或超时退出。
4. 应用运行。

## 按键监听器（快捷键）的启动与关闭

按键与鼠标监听器在初始化成功收尾时启动（`init()` 末尾），初始化失败时不启动并额外记录一条日志。

- 重复初始化不会重复启动同一个监听器。
- 关闭流程一旦开始（`after_app_shutdown`），监听器不再启动：异步初始化如果晚于关闭到达，也不会在关闭后把监听器启动起来。

## 特定应用需要

1. 运行应用。
2. 初始化 `Application.handle_init`。
3. 执行业务逻辑。

## UI需要

1. 切换到UI界面。
2. 初始化 `on_interface_shown`。
3. 刷新界面。

## 其他

1. 创建 `ZContext`。
2. 异步初始化 `ZContext.init_others`。
## 英文界面资源

英文分支使用 `assets/text/ui/en.po` 翻译界面，在构建窗口之前读取用户的语言设置。首次运行默认使用英语。新增设置项时保留原有配置值，在控件显示文字时调用 `gt()`。带变量的提示先翻译模板，再填入变量。游戏内文字识别使用独立的 `game` 词库。

修改英文 PO 后，运行 `uv run python src/one_dragon/devtools/compile_po.py` 并提交相应的英文 MO 文件。运行时从 `assets/text/output/en/LC_MESSAGES` 加载词库。
